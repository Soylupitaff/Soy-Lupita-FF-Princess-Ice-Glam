# SOY LUPITA FF — Princess Ice Glam\n\nPágina estática para GitHub Pages.\n\n- `index.html`: contenido\n- `style.css`: diseño adaptable\n- `script.js`: menú móvil y año\n- `assets/`: avatar y rango creador\n\n## Publicar\n1. Crea un repositorio nuevo en GitHub.\n2. Sube el contenido de esta carpeta (no solo el ZIP).\n3. En Settings → Pages elige Deploy from a branch, `main` y `/ (root)`.\n4. Guarda y espera a que GitHub publique el sitio.\n
